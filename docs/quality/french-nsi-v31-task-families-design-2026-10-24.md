# French NSI V31 task-family design

V30 improved reasoning depth but every seed still asked for the same selection algorithm. V31 introduces three deterministic E1 construction families: minimum available route (first tied index), all available routes within an inclusive cost budget (ordered list), and the first cumulative closure stage with no surviving listed route (stage number, 0 or None). These are distinct algorithms and reasoning obligations, not names/numbers substituted into one prompt.

All use the same explicit undirected-availability helper and the seed's original graph/catalogue. The budget is printed and deliberately equals a viable route cost to exercise the inclusive boundary. The continuity case prints three ordered closures and asks for successive survivors; repeated closures, empty input, no disconnection and the catalogue/global-graph distinction are specified. Each question has its own answer and four observable quarter-point criteria. E1 remains 70 indicative minutes, three independent exercises retain exactly 18 technical plus a distinct 2 indicative language points. Workload equivalence remains uncalibrated.

V31 is a new catalogue/version, not a rewrite of V30. Family selection is seed-bound and replay validates the canonical family, public facts, code hashes, answer and rubric. Evidence uses edge-set intersections and an independent first-hit oracle; only fixed app-owned reference code executes in tests. Historical versions retain their prior rendering and identity paths.

The package and runtime-default tests first failed before integration/default changes, then passed. Algorithm tests cover route permutations, ties, inclusive budgets, empty/all-blocked inputs, reversed and repeated closures, irrelevant closures and no input mutation. Normal/enlarged PDFs must preserve sources, answers, credit, bounds and phase order. Fresh pinned runs on three seeds must demonstrate the three families and receive direct page review against official progression before qualification. A finite three-family catalogue does not certify unlimited originality or model-independent quality. E2/E3 and broader supported-route evidence remain separately assessed.

Delivery: full tests, retained-package replay, Graphify AST/inventory refresh, clean-source live diagnostics, visual/content review, protected Backend/macOS PR checks, merge and clean main. No official PDFs bundled; no teacher, learner, accessibility or Apple approval is implied.
