## Engineering checks

The trusted reference code is tested against an independent flat-key counting oracle across all ordered integer intervals within a bounded test range, empty trees, exact boundary values and forbidden-subtree sentinels. The three mark-profile seeds also compare the reference implementation with the actual printed tree after insertion. No model-supplied program is executed.

Versioned verification records include the bounds, counted keys, count, empty-tree result, boundary cases and trusted-code hash. Package replay binds the complete candidate, catalogue, blueprint and selection evidence. Mutation tests reject changed answers and counts. Normal and large-print PDF checks require the task, source material, complete solution and credit to remain present without clipped words.
