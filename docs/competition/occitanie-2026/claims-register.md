| A distinct French Terminale NSI generation path exists | IMPLEMENTED | French education context, assessment rules, prompts, validation and rendering are separate from UK policies. |
| Papers follow the announced 2027 written structure | IMPLEMENTED | Three independent exercises, 210 minutes, 18 technical points plus a separate two-point language component. |
| PDF layout is reference-informed | INTERNALLY REVIEWED WITH LIMITS | V35 standard subjects have 34 or 36 questions over 7–9 pages. | All three exercises have locked app-owned question, answer and credit contracts | IMPLEMENTED ENGINEERING | Versioned graph/tree, SQL and network data drive French prompts, answers and exact credits; checkpoint, package replay and PDF checks preserve identity. This does not establish educational correctness or teacher approval. |
| Public French generation works without a model | IMPLEMENTED WITH FINITE SCOPE | V35 makes no AI-provider call and offers five whole-paper families. Fresh-family selection preserves exclusions; explicit repeat practice permits a labelled repeated family. This is not unlimited variety, full curriculum coverage or model-independent AI qualification. |
| The software produces examiner-approved papers | NOT CLAIMED | Teacher review is unavailable and is not a required engineering milestone. Internal review does not create teacher or examiner approval; external review fields remain not run. |
| Difficulty is equivalent to the real baccalauréat | NOT CLAIMED | Current controls constrain cognitive mix; empirical timing and difficulty require a supervised pilot. |
| Registered 2021–2026 reference files are reconciled locally | IMPLEMENTED WITH RIGHTS LIMITS | The 11 October audit verified 81 local registered files and hashes: 79 paper records plus two foundational documents. No official PDF is bundled; per-document embedded-content rights remain uncleared. See `docs/quality/french-nsi-corpus-rights-audit-2026-10-11.md`. |
| A resumable local-model benchmark exists | IMPLEMENTED | Fixed seeds, model/source/code identity, checkpoints, failure preservation and duplicate-run locking are implemented. |
| A French live benchmark has selected the best model | NOT CLAIMED | The first Gemma 4 12B campaign accepted 0/10. Earlier failures and single-paper holds remain historical evidence, not comparative qualification. The current model-free V35 route cannot qualify a model; enlarged copies and repeated families do not increase an independent sample. |
| A Toulouse/Montpellier teacher pilot exists | NOT CLAIMED | No school or teacher partnership exists. Internal review does not substitute an invented pilot. |
| Regional open data is already used in generated exercises | IMPLEMENTED SEPARATE ACTIVITY | An offline, unmarked Python/SQL activity uses twelve explicitly selected public-school records from four communes, for school year 2025–2026. The source date, Licence Ouverte 2.0, attribution and sample limits are printed. This is not a sixth paper family, an orientation service or regional endorsement. See `docs/quality/occitanie-case-study-review-2026-10-29.md`. |
