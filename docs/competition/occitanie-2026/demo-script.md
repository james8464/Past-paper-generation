# Demonstration video script

Target length: 2 minutes 30 seconds. Record the real macOS application at 1920 × 1080 or higher. Do not use mock screens, fabricated model results or an unreviewed paper presented as approved.

## Recording prerequisites

- Use a stable committed build and record the commit hash.
- Keep notifications, personal files and API credentials off screen.
- Use local Ollama mode and show the model name without exposing unrelated models or paths.
- Prepare one generated French assessment whose subject, correction and validation manifest all match the recorded commit and model digest.
- Mark the artifact as non-official and non-reviewed unless a real teacher review is attached to those exact hashes.

## Shot list and narration

### 0:00–0:15 — The problem

Visual: title card, then the French workspace landing screen.

Narration: “Teachers need new practice questions, but a plausible-looking AI answer is not enough. Paper Creator generates an original French NSI practice paper and keeps the checks, sources and human decision attached to it.”

### 0:15–0:35 — French assessment rules

Visual: session 2027 information, three exercises, 3 h 30, local model selection and non-official status.

Narration: “The French path is separate from the existing British paths. It uses the announced 2027 written structure: three independent exercises, eighteen technical points and a separate two-point language component.”

### 0:35–1:00 — Local generation

Visual: choose the local model, start generation, show progress and the evidence/checkpoint view.

Narration: “Generation runs locally through Ollama. Each exercise is planned against programme capabilities, generated in French, solved independently and checked. Failed attempts remain evidence; the application does not silently publish a partial result.”

### 1:00–1:25 — Question quality

Visual: open one context-rich exercise, a code listing or SQL task, a vector graph and the corresponding proposed correction.

Narration: “The model cannot pass merely by labelling a question difficult. The structure requires a progression from application to analysis, design, debugging or justification. Deterministic checks cover supported SQL, traces, binary results, graph consistency and exact credit totals.”

### 1:25–1:45 — PDF fidelity

Visual: show the generated subject beside the public 2026 Métropole reference, focusing on cover hierarchy, exercise headings and code typography. Keep independent branding visible.

Narration: “The A4 profile is measured from an official historical paper, including typography and placement. It intentionally keeps independent branding and the words ‘entraînement non officiel’; visual similarity must never imply official status.”

### 1:45–2:05 — Teacher decision

Visual: review panel, validation failures, artifact hashes and review decision.

Narration: “Automation is not examiner approval. A teacher sees unresolved limits and records a decision tied to the exact PDF hashes. Any change invalidates that review.”

### 2:05–2:25 — Occitanie pilot

Visual: simple diagram of teacher Mac to PDF to ENT, loRdi or paper; then the twelve-month pilot plan.

Narration: “For students, the result is an ordinary PDF on the ENT, loRdi or paper. The Prix Occitanie would fund two NSI reviewers, a supervised regional pilot, accessibility tests and an optional context module based on licensed regional open data.”

### 2:25–2:30 — Honest close

Visual: Paper Creator icon and project title.

Narration: “The technical prototype works. The prize would finance the evidence needed to decide whether it deserves classroom use.”

## Short version

For a 35-second teaser, use the problem, one generation/check shot, one PDF comparison and the teacher-decision screen. End with: “A local, inspectable tool for original NSI practice papers—qualified with teachers, not declared correct by AI.”
